This is Project UNO Reverse a project made by two sigmas: BrandØo and TheeA1pha. The project that we made is a custom code project that takes readings from an ultrasonic sensor which would then display the measured distance in Centimeters as well as custom reactions that we made on an LCD (Liquid Crystal Display). To make this project work, we used Arduino and programmed it to produce readings onto the LCD from the sensor that was collecting data. We used our prototype code which is called Prototype_UNO which we built up from to create our final project. 

When creating Project UNO we came across a few issues when coding and wiring our Arduino. One of the few problems that we came across was that whenever we executed our code for the ultrasonic sensor to collect data, the serial monitor would only display that the distance between the sensor and the object would only be 0cm. To fix this, we replaced our sensor which was a 3 pin with a 4 pin sensor to see if there was a problem with the compatibility of the sensor, we tried the code again with the same result, so we replaced wiring which resolved the issue as the cable pins were most likely bent. Another problem we came across but managed to solve was with our LCD display. When writing the code, the LCD display would not display the distance measured being shown by the serial monitor which was a coding problem. Threfore we had to debug the code in which the problem was that we used code for and LCD I2C display rather than a regular 16x2 display and once we put the correct code, the display worked as it was supposed to.
